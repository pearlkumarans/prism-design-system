Popover

The Popover is a non-modal overlay anchored to a trigger — an optional header (title + close), a body for rich content, and an optional footer for actions, with an optional arrow pointing at the trigger. Use it for contextual detail, lightweight forms, or supporting actions that should appear beside an element without leaving the page. Width hugs its content (240px floor); it anchors at one of twelve placements, flips on collision, clamps to the viewport, and dismisses on outside-click, Esc, or the close button.

Content GuidelinesRecommended

Do
  • Anchor the popover to the element that triggered it and keep them visually connected.
  • Keep content focused — a short title, concise body, and at most a couple of actions.
  • Turn the arrow on to make the relationship to the trigger explicit.
  • Dismiss on outside-click and Esc; provide a close button when there's a header.
  • Let the surface hug its content, or set --ds-popover-width for longer prose.
  • Return focus to the trigger when the popover closes.
Don't
  • Put a long form or multi-step flow in a popover — use a Drawer or Modal.
  • Open a popover from inside another popover, or nest them.
  • Trigger it on hover — that's a Tooltip's job.
  • Use it for a menu of choices — reach for a Dropdown.
  • Hardcode the surface or border colors — use the --uems-* tokens.
  • Block the page behind a scrim — the popover is non-modal by design.

Style

Placement, arrow, header, footer, sizing, and RTL that define the Popover's visual language. Each card forces an anchorless surface visible inside a frame — use Show code to reveal the markup.

Placements

Set placement="<side>-<start|center|end>" — top, bottom, left, or right with an alignment (default bottom-start). The arrow sits on the edge facing the anchor; at runtime the popover flips and clamps to stay on-screen.

Below the anchor; the beak points up at the trigger.

Header options

A header appears automatically when title is set (or force it with has-header). Drop the close button with hide-close, drop the bottom divider with hide-divider, or omit the title for a header-less surface.

title + close (default)

Title on the left, close ✕ trailing, with a bottom divider.

hide-close

The close ✕ is hidden; dismiss on outside-click or Esc.
HTML
<ds-popover anchor="trigger" hide-close title="No close button">…</ds-popover>
hide-divider

The header's bottom divider is removed for a flush look.
HTML
<ds-popover anchor="trigger" hide-divider title="No header divider">…</ds-popover>
no header

With no title and no has-header, the body fills the surface.

  <p>Body only — no header.</p>
</ds-popover>

Footer

The footer is off by default; it appears when you provide a slot="footer" (or force it with has-footer). Children are unwrapped into the footer row. footer-align="centered" centers the button group; the default right-aligns it.

Right-aligned button group with a top divider.

Sizing

Width hugs content with a 240px floor and no max — longer content makes the popover wider. To wrap long prose, set a fixed width with the --ds-popover-width CSS variable (or an inline width).

hug content (default, 240px min)

Short body — the surface stays at the 240px minimum.
HTML
<ds-popover anchor="trigger" title="Hugs content">…</ds-popover>
--ds-popover-width: 280px

With --ds-popover-width set, long body text wraps within the chosen width instead of growing the surface indefinitely.
HTML
<ds-popover anchor="trigger" title="Fixed width"
  style="--ds-popover-width:280px;">…</ds-popover>

RTL

Add rtl (or host dir="rtl") to mirror the layout: the close ✕ moves left, the title right-aligns, the body right-aligns, and the footer group moves to the leading (left) edge. The title uses rtl-title (Arabic) when set, and the arrow's start/end inset mirrors.

Usage

When to reach for the Popover versus its overlay siblings.

When to use

  • Contextual detail or supporting content tied to a specific trigger, shown beside it without leaving the page.
  • A lightweight, focused action set — a couple of buttons or a small form-let next to the element they affect.
  • Rich content (text, a thumbnail, links) that's too much for a Tooltip but doesn't warrant a Drawer or Modal.
  • Inline confirmations or quick edits that should stay non-blocking while the page remains interactive.

When not to use

  • Plain hover text or a short label — use a Tooltip.
  • A menu of selectable options or actions — use a Dropdown.
  • A long form, multi-step flow, or dense detail — use a Drawer or Modal.
  • A decision that must block the page until resolved — use a Modal (the popover is non-modal).

Do & Don't

Do
  • Anchor the popover to the trigger and keep them visually connected.
  • Keep content focused — short title, concise body, minimal actions.
  • Dismiss on outside-click and Esc; return focus to the trigger on close.
Don't
  • Put long forms in a popover — use a Drawer or Modal.
  • Nest popovers or open one from inside another.
  • Rely on hover to open it — that's a Tooltip.

Install & usage

Register the component, then drive it with attributes and slots. Source: design-system-library/src/components/popover/popover.js.

Register the component

JS
<script type="module" src="design-system-library/src/components/popover/popover.js"></script>

Basic markup

HTML
<ds-button id="trigger" variant="outline">Open popover</ds-button>

<ds-popover anchor="trigger" placement="bottom-start" arrow title="Popover title">
  <p>Body content goes here.</p>
</ds-popover>

Set the anchor to the trigger's id and the popover wires the click toggle and aria-* automatically.

All attributes

HTML
<ds-popover
  anchor="trigger"          <!-- id of the trigger element -->
  placement="bottom-start"  <!-- top|bottom|left|right (+ -start|-center|-end) -->
  title="Popover title"
  rtl-title="عنوان منبثق"     <!-- shown when rtl -->
  has-header             <!-- auto-on when title set -->
  hide-close
  hide-divider           <!-- hide header bottom divider -->
  has-footer             <!-- auto-on when footer slot present -->
  footer-align="default"  <!-- default | centered -->
  arrow                  <!-- show the beak (default off) -->
  rtl
  open>
</ds-popover>

Slots

HTML
<ds-popover anchor="trigger" title="With actions">
  <!-- default slot → body -->
  <p>Body content goes here.</p>

  <!-- slot="footer" → action region (children unwrapped) -->
  <div slot="footer">
    <ds-text-link href="#">Learn more</ds-text-link>
    <ds-button variant="primary" size="small">Save</ds-button>
  </div>
</ds-popover>

Events & methods

JS
const popover = document.querySelector('ds-popover');

// Methods
popover.open();
popover.close();
popover.toggle();

// Events
popover.addEventListener('ds-popover-open', () => {});
popover.addEventListener('ds-popover-close', (e) => {
  console.log(e.detail.reason); // 'esc' | 'outside' | 'close' | 'api'
});

Accessibility

Guidelines for an accessible Popover across assistive tech and input methods.

Roles & ARIA

ConcernImplementation
Rolerole="dialog" with tabindex="-1" on the surface.
Namearia-labelledby points to the title when present; otherwise aria-label falls back to "Popover".
Triggeraria-haspopup="dialog", aria-controls to the popover id, and aria-expanded reflecting open state.
Close buttonaria-label="Close".
ArrowDecorative — aria-hidden="true".

Keyboard & focus

Key / actionBehavior
Enter / Space on triggerOpens (or toggles) the popover.
EscDismiss (emits ds-popover-close with reason esc).
Tab / Shift+TabMoves through the popover's content; focus softly cycles within the surface while open.
Click outsideDismiss (reason outside).
  • Non-modal: focus is not trapped — on open, focus moves into the popover (first focusable, or the surface).
  • On close, focus returns to the trigger (or the element focused before opening).

Other concerns

ConcernRequirement
Non-modalThe page stays interactive — no scrim, no body scroll-lock. Page content behind the popover remains reachable.
Color contrastTitle --uems-text-primary and body --uems-text-secondary on the surface meet WCAG 2.1 AA.
Motionprefers-reduced-motion: reduce removes the open animation (instant show).
RTLrtl (or host dir="rtl") mirrors header order, text alignment, footer group, and the arrow start/end inset; the title uses rtl-title.
Off-screen anchorThe popover clamps to an 8px viewport margin and flips toward available space to stay on-screen.
