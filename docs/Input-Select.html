Input select

An input select lets the user pick a single value from a list of options. It looks like a text field with a chevron; clicking it opens a dropdown of options anchored to (and the same width as) the field. Use it when the answer is one item from a known set. For picking several values at once, use the Token Field instead.

Anatomy

1
LabelIdentifies the field, with an optional required indicator (*).
2
Field / triggerThe combobox container — border, background, and all inner elements.
3
PrefixOptional leading text and/or icon for context. Off by default.
4
Value / placeholderThe selected option label, or the placeholder when empty.
5
ClearAn × to reset the selection. Shown only when a value exists.
6
ChevronStatic dropdown indicator (does not rotate or swap when open).
7
SuffixOptional trailing text and/or icon, after the chevron. Off by default.
8
Helper rowSupporting text / validation message below the field.
9
DropdownThe option list (ds-dropdown-menu), matched to the field width.

When to Use

Reach for an input select when the user picks one value from a known list and you want a compact, form-aligned control.

  • Single choice from a set: country, status, category, owner — one value at a time.
  • Form fields: as a drop-in alongside Text field in standard forms (same sizes, label, helper, states).
  • Filters: dense table toolbars and dashboards where a native select looks out of place.
  • Autocomplete: long option lists the user filters by typing.

Single vs. multiple

Input select is for a single value. When the user needs to pick several, use the Token Field, which shows each choice as a removable chip.

✓ Do
  • Use Input select for one value (status, country, owner).
  • Match the dropdown width to the field.
  • Keep option labels short and scannable.
× Don't
  • Force multi-select into this control — use Token Field.
  • Use it for free-text entry — use Text field.
  • Hide the selected value behind a generic "Selected".

Prefix & Suffix

Both are off by default. Turn them on for fixed context the user shouldn't have to read from the option labels.

ElementPositionExampleUse Case
Prefix iconLeadingglobe, searchVisual context for the field's purpose.
Prefix textLeading"Region"A fixed qualifier before the value.
Suffix textTrailing (after chevron)"UTC"Units or a fixed trailing qualifier.
Suffix iconTrailing (after chevron)info-circleSecondary context or a help affordance.

RTL Support

Set rtl (or an ancestor dir="rtl") and the whole field mirrors — label, prefix/suffix, chevron, clear, and helper row all swap sides.

  • Layout mirrored: prefix moves to the right, suffix and chevron to the left.
  • Dropdown: the option list mirrors and stays matched to the field width.
  • Text alignment: value, placeholder, and helper start from the right.

Accessibility

The field follows the WAI-ARIA "select-only combobox" pattern.

  • The trigger is role="combobox" with aria-haspopup="listbox", aria-expanded, and aria-controls pointing at the option list.
  • The option list is role="listbox"; each option is role="option" with aria-selected.
  • Required fields set aria-required="true"; the asterisk is decorative (aria-hidden).
  • Error state sets aria-invalid="true" and links the helper via aria-describedby.

Keyboard Navigation

KeyAction
Enter / Space / ↓Open the dropdown and move into the option list.
↑ / ↓Move the active option; Home/End jump to ends.
EnterSelect the active option and close.
EscapeClose without changing the selection; focus returns to the field.
TabClose and move to the next focusable element.

Screen Reader

  • Associate a <label> with the trigger so the field name is announced.
  • Announce expanded/collapsed state and the active option as it changes.
  • After autocomplete filtering, announce the result count via a live region.
  • The clear button has an explicit aria-label="Clear selection".

Disabled & Read Only

  • Disabled: trigger is aria-disabled and removed from tab order; the menu cannot open.
  • Read Only: trigger stays focusable but the menu does not open and the value cannot change.
  • Never rely on colour alone for error — always pair the red border with helper text.
