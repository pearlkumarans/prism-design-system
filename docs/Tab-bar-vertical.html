Tab Bar Vertical

A vertical tab bar stacks the same kind of choices down the side of the screen — settings sections, profile pages, steps in a flow. Use it when labels are long, there are more than five options, or the content area to the right is wide enough to deserve a fixed left rail. Pick Underline for sidebar-style nav, Fill for a compact picker inside a panel.

Variants

Two visual types of Tab Bar Vertical, each suited to a different navigation density.

Type Active treatment Best for Examples
Underline 2px left-border on active row. Sidebar nav — reads as a list of destinations. Quietest visual weight. Profile · Security · Notifications · Billing
Fill Soft-blue pill behind active row. Embedded picker inside a card or panel; works when surrounding chrome is neutral. Inbox · Drafts · Sent · Archive

Rule of thumb: if the parent surface is tinted, use Underline. If it's plain, either works — pick Fill when you want stronger active feedback.

Content GuidelinesRecommended

Do
  • Use Underline for sidebar nav — it reads as a list of destinations.
  • Use Fill for grouped pickers and embedded navigation.
  • Keep labels short — 1–3 words, sentence case, ≤ 18 chars.
  • Use icons consistently — every row or no row.
  • Persist the selected tab in the URL or query string.
  • Reserve 160–240px for the rail; anything narrower truncates labels.
  • Show numeric badges for inbox / queue rows (Inbox · 4).
Don't
  • Use Tab Bar Vertical for > 10 destinations — switch to a scrollable side nav.
  • Use Underline as a menu picker — the lack of grouping makes the bar feel loose.
  • Use Fill on a tinted parent surface — its container relies on a neutral backdrop.
  • Truncate labels mid-word.
  • Reset the active tab when the user navigates back.
  • Stack two Tab Bar Verticals in the same panel — group instead with a section header.
  • Use a textual badge (New!) — the slot is for numeric counts only.

When to use

  • Settings or profile screens — Account, Notifications, Billing, Security.
  • Vertical menu pickers — Type=Fill works for compact pickers.
  • Step lists or progress trackers with ≤ 10 steps.
  • Documentation or admin panels where the navigation is content-adjacent.

When not to use

SituationUse instead
More than 10 destinations or unknown countScrollable side navigation
Top-level product navigationApp shell / global side nav
Inline switching of content layoutsTab Bar Horizontal
Hierarchical (parent → child) navigationTree / nav with disclosure
