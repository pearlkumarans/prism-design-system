List

A styled list block — the design-system equivalent of <ul>/<ol> with seven marker styles (disc, circle, square, custom icon, number, letter, and numbered pill badge), three sizes, and three nesting levels. Purely presentational: it carries typography and markers, no states or interaction. Reach for it whenever you would write a bulleted or numbered list — feature lists, steps, summaries — and compose with Link or Checkbox when items must become interactive.

Anatomy

A list is a stack of rows; each row is a marker plus text. The marker is centred to the first text line, so multi-line items hang under the text.

When and where to use

A list carries typography and markers only — keep it presentational.

When to use

  • Bulleted feature or summary lists (unordered styles).
  • Sequential steps or ranked items (ordered styles).
  • Status checklists with the custom-icon style.
  • Short nested hierarchies (up to 3 levels).

When NOT to use

  • For interactive rows — use Link, Checkbox, or a menu.
  • For tabular data — use the Data table.
  • Nesting beyond ~3 levels — hard to scan.
  • Mixing marker styles within one list.

Accessibility

Lists render as real semantic elements so assistive tech announces size and position.

ConcernGuidance
SemanticsRenders real <ul>/<ol> + <li> — screen readers announce list size and position
MarkersDrawn via CSS ::before / aria-hidden SVG, so they are not read as content
Ordered semanticsnumber / letter / badge render as <ol> — order carries meaning
NestingPrefer real nested lists where the hierarchy must be announced; level is a visual fallback
ContrastItem text #15181E on white passes AAA; markers are decorative (#5F6C89 ≥ 3:1 anyway)
