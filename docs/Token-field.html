Token Field

A token field is a multi-select input where each chosen value becomes a removable token sitting inside the field — skills on a profile, recipients on a message, labels on a ticket. Type to filter suggestions, press Enter to add, click a token's × to remove it. At rest it collapses to a single tidy row with a +N total; while you're picking, it expands to show up to three rows of tokens — as a floating overlay, so the page below never shifts.

When to use

  • Use a token field when a user picks several values from a (possibly large) set and needs to see and remove each choice — skills, tags, recipients, filters, label assignment.
  • Use Input Select instead when only one value is chosen, or when the field should stay a fixed single line and never expand.
  • Use a Text Field for a single free-form value with no tokens.

Best practices

Do
  • Collapse the resting field to one row with a +N total so dense forms stay scannable.
  • Expand on focus so the user can review every token while picking (cap at 3 rows, then scroll).
  • Offer suggestions where a known catalog exists; allow free entry (creatable) only for open vocabularies like tags.
  • Make every token removable and keep Backspace-removes-last working.
Don't
  • Don't let the field grow unbounded — three rows is the ceiling, then scroll inside.
  • Don't hide the count: if tokens overflow the resting row, always show +N.
  • Don't use it for a single choice — that's an Input Select.
  • Don't rely on color alone for error; pair the red border with helper text.

Roles & semantics

  • The caret is a combobox (aria-autocomplete="list", aria-expanded); the suggestions are a listbox of options.
  • Tokens form a labelled group; each token's close × is a real button labelled “Remove {label}”.
  • The field is described by the helper row (aria-describedby); error state sets aria-invalid.
  • Token count changes are announced via an aria-live="polite" region.

Internationalisation

  • rtl mirrors the whole field: tokens flow right-to-left, chevron flips, label and helper right-align.
  • Long token labels truncate with ellipsis (full text in title); the close × never truncates.
  • App supplies localized token + suggestion labels; the +N badge has an accessible label.
