Dual list

A two-panel transfer control (shuttle / pick-list). Users move items between an Available list and a Selected list using per-item checkboxes and transfer buttons. Use it for assignment tasks — pick report columns, assign agents to a group, choose dashboard widgets, toggle features per module.

When to use

  • Assigning many items between two buckets where users need to see both sides at once.
  • Multi-select from a large pool where search + bulk move matter (10+ items).
  • When order in the target matters, enable reorderable.

Do's and Don'ts

Do
  • Enable searchable once either list can exceed ~10 items.
  • Use locked for mandatory selections instead of hiding them.
  • Keep item labels short and scannable (1–4 words).
Don't
  • Use a dual list for a single choice — use ds-input-select or radios.
  • Show move-all when the lists are tiny; single moves are clearer.
  • Hardcode colors or spacing — everything comes from tokens.

Component API & Properties

Data is set via the .items JS property (or an items JSON attribute): { available:[{id,label,group?,locked?,disabled?}], selected:[…] }.

AttributeTypeDefaultDescription
available-label / selected-labelstring'Available' / 'Selected'Panel header titles.
search-placeholderstring'Search…'Placeholder for both search fields.
searchablebooleanunsetSearch field in both panels (client-side filter).
move-allbooleanunsetAdds the » / « move-all buttons.
reorderablebooleanunsetAdds ▲▼ reorder controls for Selected.
groupedbooleanunsetRenders section headers from each item's group.
loadingbooleanunsetSkeleton rows; search + controls disabled.
readonlybooleanunsetView-only — no controls, search, or select-all.
error / error-messageboolean / stringunsetError border + message via ds-field-helper.

Item flags: locked, disabled. CSS var --ds-dl-height sets panel height. Emits ds-dual-list-change → detail = { available:[ids], selected:[ids] }.

Usage

<ds-dual-list id="assign" searchable move-all></ds-dual-list>
<script type="module">
  const el = document.getElementById('assign');
  el.items = {
    available: [{ id: 'ben', label: 'Ben Ortiz' }],
    selected:  [{ id: 'ava', label: 'Ava Chen', locked: true }],
  };
  el.addEventListener('ds-dual-list-change', (e) => {
    console.log(e.detail.selected);
  });
</script>

Accessibility

  • Each panel is role="group" labelled by its header title (the count is part of the accessible name).
  • Lists are role="listbox" aria-multiselectable; rows are role="option" whose aria-selected mirrors the checkbox.
  • Transfer controls are real <button>s with aria-labels; disabled when there is nothing to move.
  • A polite live region announces each move — "Moved 3 items to Selected. Selected now has 5."
  • Error: panels get aria-invalid; the message is linked with aria-describedby.
  • Focus order: Available (select-all → search → list) → transfer controls → Selected.
