Tab Bar Horizontal

A horizontal tab bar lets the user flip between related views of the same thing — Overview / Activity / Settings on a profile, Open / Resolved / Archived on a ticket list. Pick Fill when the group should feel like a compact picker (good in toolbars); pick Underline when the tabs sit under a page title and the active one should anchor the section below.

Variants

Two visual types, each suited to a different navigation pattern. Pick by how prominent the selected state needs to be relative to surrounding chrome.

Type Active treatment Best for Examples
Underline 2px bottom-border on active label. Content-section navigation under a page heading. Quietest visual weight. Overview · Members · Activity · Settings
Fill Soft-blue pill behind active label. Grouped pickers where one option is "checked" out of a small set. Day · Week · Month

Rule of thumb: if changing the tab loads peer-level content → Underline. If it just re-scopes the same view → Fill (or consider Tab Filter).

Content GuidelinesRecommended

Do
  • Use Underline for content-section navigation under a page heading.
  • Use Fill for grouped pickers (Day / Week / Month, List / Grid).
  • Keep labels short and parallel — same part of speech across all tabs.
  • Persist the selected tab in the URL (?tab=members) so deep links work.
  • Cap labels at ~18 characters and use icons consistently — every tab or none.
  • Show a numeric badge for queue / count tabs (Inbox · 12).
  • Allow horizontal scroll on narrow viewports rather than wrapping to two rows.
Don't
  • Use Tab Bar Horizontal for global product navigation.
  • Use Underline as a picker for short, mutually-exclusive options — use Tab Filter.
  • Place Fill on a tinted parent surface — its container has no background.
  • Mix nouns and verbs in tab labels.
  • Allow label truncation — switch to a scrollable tab pattern instead.
  • Use more than 10 tabs — consolidate or move to a sidebar.
  • Use a textual badge (New!) — the slot is for numeric counts only.

When to use

  • In-page section switchers — Overview, Activity, Settings on a single object.
  • Content-level navigation within a card, panel, or modal.
  • Filtered views over a single dataset — All / Open / Closed.

When not to use

SituationUse instead
Top-level product navigationApp shell / global side nav
Mutually-exclusive form optionsTab Filter or Radio Group
Number of tabs unknown or > 10Scrollable tab pattern with overflow menu
Vertical content alongside the barTab Bar Vertical
