Search Field

A search field is where the user types something they want to find — a name in a directory, a row in a table, a doc in a workspace. The leading magnifying glass tells them what the field is for, the ⌘K hint tells them how to jump to it from anywhere, the X clears it in one click, and the spinner tells them results are on the way.

Anatomy

1 2 3
1
Leading search iconAlways present. 16 px (Small) / 20 px (Medium, Large). Color tracks state.
2
Placeholder / ValuePlaceholder shows when empty; primary text once filled. Native <input type="search">.
3
Trailing slotOne of: ⌘K shortcut chip (idle) → Clear (×) button (filled / error) → spinner (loading).

Content GuidelinesRecommended

Do
  • Keep the leading search icon visible at all times.
  • Show the Clear (×) once the field has a value.
  • Use the Loading state for async / debounced queries.
  • Reserve the Error state for failed or empty results — not for "no input yet".
  • Show ⌘K only when a real keyboard shortcut is wired up.
Don't
  • Replace the search icon with an unrelated glyph.
  • Leave a filled field with no way to clear it.
  • Block the UI while searching — use the inline spinner instead.
  • Use Error styling for an empty / resting field.
  • Display a shortcut hint that doesn't actually focus the field.

Animation

  • Border / background — fade over 160 ms cubic-bezier(0.4, 0, 0.2, 1) on every state change.
  • Clear button — hover bg fade 140 ms; press scale(0.9) with cubic-bezier(0.16, 1, 0.3, 1).
  • Spinner — 0.7 s linear infinite rotation (GPU-accelerated transform).
  • Focus ring — width swap 1 → 2 px animated via border-color; padding auto-compensates so height stays 32 / 40 / 48 px.
  • Reduced motion — @media (prefers-reduced-motion: reduce) disables every transition and the spinner animation.

When to use

  • To filter, find, or query a list, table, dataset, or the whole product.
  • As a global search entry point (pair with the ⌘K shortcut hint).
  • Inline within toolbars, headers, navigation, or data views.

When NOT to use

  • For free-form text that isn't a query — use a standard Text Input.
  • For selecting from a small known set — use a Select / Combobox.

Choosing the right size

ContextSize
Dense toolbar, inline list filter, sidebar palettesmall (32 px)
Global header search, content-area searchmedium (40 px)
Hero search (landing, search-only screen)large (48 px)

Related components

  • Text Input — general-purpose single-line text entry.
  • Select / Combobox — choosing from a known set of options.
  • Filter / Tag — narrowing results after a search.

AttributeTypeDefaultDescription
size'small' | 'medium' | 'large''small'Field height — Small in toolbars, Medium in standard forms, Large on touch and mobile.
placeholderstring—Shown when the field is empty. Use it for an example query, not as a substitute for a label.

show-shortcutbooleanfalseRenders the trailing ⌘K chip. Use it whenever the field is reachable from anywhere via a keyboard shortcut.

loadingbooleanfalseBorder turns brand blue and a spinner replaces the trailing slot while results are fetched; sets aria-busy="true".
disabledbooleanfalseNon-interactive and skipped by Tab. Use only when the field genuinely can’t be searched yet.

rtlbooleanfalseMirrors the layout for Arabic, Hebrew, and Persian — search icon flips to the trailing edge, shortcut and Clear flip to the leading edge.

Built on a native <input type="search">, so keyboard and screen readers work out of the box. Listen for ds-search-field-input on every keystroke (debounce before hitting your API), ds-search-field-submit when the user hits Enter, and ds-search-field-clear when they tap the × or press Esc.

Global search with ⌘K + Enter / Esc handling

<ds-search-field id="global-search" size="medium" placeholder="Search anything" show-shortcut></ds-search-field>

<script>
  const el = document.getElementById('global-search');

  // Enter triggers submit; the component fires ds-search-field-submit.
  el.addEventListener('ds-search-field-submit', (e) => {
    fetch('/api/search?q=' + encodeURIComponent(e.detail.value))
      .then(r => r.json()).then(renderResults);
  });

  // ⌘K (or Ctrl+K) from anywhere focuses the field.
  document.addEventListener('keydown', (e) => {
    if ((e.metaKey || e.ctrlKey) && e.key === 'k') {
      e.preventDefault();
      el.focus();
    }
  });
</script>

Debounced async filter with loading + error states

<ds-search-field id="table-filter" size="small" placeholder="Filter by name…"></ds-search-field>

<script>
  const el = document.getElementById('table-filter');
  let t, ctrl;
  el.addEventListener('ds-search-field-input', (e) => {
    clearTimeout(t); ctrl?.abort();
    const q = e.detail.value;
    if (!q) { el.removeAttribute('loading'); el.removeAttribute('error'); return; }
    t = setTimeout(async () => {
      el.setAttribute('loading', ''); el.removeAttribute('error');
      ctrl = new AbortController();
      try {
        const data = await fetch('/api/filter?q=' + q, { signal: ctrl.signal }).then(r => r.json());
        renderTable(data);
      } catch (err) {
        if (err.name !== 'AbortError') el.setAttribute('error', '');
      } finally {
        el.removeAttribute('loading');
      }
    }, 250);
  });
</script>

Accessibility

Role & semantics

  • The component renders a native <input type="search"> with no custom role override — screen readers expose it as a search field automatically.
  • Provide an accessible name via aria-label="Search" on the host or a visually-hidden <label>; or wrap in <form role="search"> for landmark navigation.
  • The Clear button has an explicit aria-label="Clear search".

Keyboard interaction

KeyBehavior
Tab / Shift+TabFocus / unfocus the field (natural tab order).
EscClears the value (fires ds-search-field-clear with source: 'keyboard') and keeps focus on the input.
EnterFires ds-search-field-submit with the current value.
⌘K / Ctrl KMust be wired by the consumer to call el.focus() — the chip is purely informational.

ARIA state mirrors

  • loading attribute → sets aria-busy="true" on the input.
  • error attribute → sets aria-invalid="true".
  • disabled attribute → sets the native disabled property (no aria-disabled needed).
  • For async results, annotate the results container with aria-live="polite" so updates are announced.

RTL

Set the rtl attribute (or rely on document.dir = "rtl") — the search icon moves to the trailing (right) edge, text aligns right, and the shortcut/clear affordances flip to the leading (left) edge per MD §RTL.
