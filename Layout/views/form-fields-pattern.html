Form field alignment pattern

Every Prism form field, left label (280px) + medium control, in a uniform 20px stack. Labels and controls should align to the dashed guide; spacing between fields should be identical whether or not a field shows a helper/counter.

Left-label form fields

Every field uses its built-in label at label-position="left" + size="medium". Labels sit in a shared 280px column; controls all start at the dashed guide.

Controls without a left-label layout

These are form controls too, but they don't expose label-position="left" — they render top-label or inline by design, so they don't join the 280px column above. (Giving them a left-label mode would be a component change.)
