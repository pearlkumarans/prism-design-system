# `<ds-split-button>`

Compound primary action + chevron dropdown trigger.

| Attribute | Values | Default |
|---|---|---|
| `size` | `large` \| `medium` \| `small` \| `xsmall` | `small` |
| `variant` | `primary` \| `outline` | `primary` |
| `label` | string | slotted text or `Action` |
| `icon` | sprite name | — |
| `disabled` | boolean | — |
| `rtl` | boolean | — |

Events: `ds-split-button-main` (primary clicked), `ds-split-button-menu` (chevron clicked — open your dropdown here).
