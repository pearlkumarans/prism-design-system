Behaviors

  • Header and footer stay pinned; only the body scrolls.
  • A soft shadow appears under the header divider when the body has been scrolled to indicate offscreen content.
  • Esc and backdrop click both dismiss by default — set dismiss-on-esc="false" / dismiss-on-overlay-click="false" when there's unsaved state.
